# Humanizer ZH (中文表达自然化)

## 核心原则
1. **消除翻译腔**: 避免死板硬译（例如过度使用“为了...”、“被...”）。
2. **术语地道性**: 针对计算机、前端和图形学术语，采用中文技术社区通用标准表达。
3. **节奏与标点**: 正确使用半角与全角空格、中英混排规则（中英文之间加半角空格）。
